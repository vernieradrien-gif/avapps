# AVApps

Pages publiques des applis AVApps, publiées avec GitHub Pages.

- `incognito/confidentialite.html`, `incognito/privacy.html` (anglais) et `incognito/privacidad.html` (espagnol) : règles de confidentialité de !ncognito. Elles sont générées à partir de `js/privacy.js` du dépôt de l’appli (dossier `site/`) : modifie ce fichier-là, puis recopie les pages ici.
